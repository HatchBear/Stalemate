Stalemate

Closed Alpha · Field Guide

A free companion app for Deadlock. It scouts the players in your match, follows the enemy team's items while you play, and reviews your match when it ends. This guide gets you installed, set up, and testing everything the Alpha can do.

Stalemate is free software (GPL-3.0). It isn't made by, affiliated with, or endorsed by Valve. It never reads the game's memory, changes its files, or sends it input. Everything it shows comes from data Deadlock and the public deadlock-api already make available, and only what you could see in the game yourself.

01

Install

Use the file you were sent. Alpha builds are private, so they aren't on Flathub, the AUR or any store yet. Pick one way for your system.

Linux: Flatpak

Any distroRecommended

Needs the free Flathub repository for the KDE runtime.

flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./stalemate.flatpak
flatpak run io.github.hatchbear.stalemate

It works with both normal Steam and Flatpak Steam.

Debian, Ubuntu, Mint, Pop!_OS

.deb 
sudo apt install ./stalemate_<version>_amd64.deb
stalemate

Ubuntu 22.04 or newer, or Debian 12 or newer.

Fedora, openSUSE

.rpm 
sudo dnf install ./stalemate-<version>-1.x86_64.rpm
stalemate

Arch, CachyOS, anything else

AppImagetarball

AppImage: no install needed.

chmod +x Stalemate-<version>-x86_64.AppImage
./Stalemate-<version>-x86_64.AppImage

Tarball: unpack it and run ./stalemate from the folder. Keep the config and i18n folders next to it. The AUR package arrives with the public release.

Windows 11: installer

.msi
  1. Double-click stalemate-<version>-x64.msi. It installs for you only and needs no admin rights.
  2. Windows shows "Windows protected your PC", because Alpha builds aren't code-signed yet. Choose More info, then Run anyway.
  3. Open Stalemate from the Start menu.

Windows 11: portable

.zip

Unzip stalemate-<version>-windows-x64-portable.zip anywhere and run stalemate.exe. Keep the config and i18n folders next to it. You'll see the same SmartScreen warning the first time.

To check which build you have, run stalemate --version. It prints the version and the package type, for example stalemate 0.1.0 (flatpak).

02

Set up

Turn on the game log

Stalemate learns when a match starts from a log file Deadlock writes. Deadlock only writes it with the -condebug launch option.

  1. In Steam, open your Library and right-click Deadlock.
  2. Choose Properties, then stay on the General tab.
  3. In Launch Options, type -condebug.
  4. Start Deadlock, reach the main menu, then press Check again in Stalemate.

The setup checks

Home lists every check with a stamp: Pass   Fail   Pending

  • Steam found: it looks in the usual places for normal and Flatpak Steam on Linux, and in the registry on Windows.
  • -condebug working: it passes once Deadlock has written its log with the option on.
  • Account ID: it's read from Steam automatically. If it fails, enter it in Settings. It's the number in your Steam friend code (Friends, Add a Friend).
  • Match detection, Broadcast and deadlock-api: the parts that follow your match.
03

Features to try

Play a normal match with Stalemate open. Each card says what to do and what you should see. If what you see doesn't match, press Mark a problem (see section 04).

Home

  • Open Stalemate before you start Deadlock.
  • Queue for a match.
  • Optional: paste a match ID into Watch a match to follow a match you're not in.
You should see
The status change to "match detected" within a few seconds of the match loading, then to Live.

Scouting

  • Open Scouting once your match has started.
  • Check a card for each player: hero, overall record, last 20 matches, rank, top 5 heroes, games on this hero and MMR trend.
  • Your team shows its side, Amber or Sapphire.
You should see
Cards filling in over a few seconds. Players who opted out of public data show No public data. That's correct, and Stalemate never works around it.

Live: enemy board and Purchase Log

  • Open Live during the match.
  • Each enemy shows their items as tiles in the shop's colours, WeaponVitalitySpirit, along with souls, level and K/D/A.
  • The Purchase Log lists buys, upgrades and sells as they happen.
You should see
Everything a little behind the game. The Broadcast delay bar at the top says by how much. Only what the in-game scoreboard would show you appears here. Positions, cooldowns, health and chat never do.

Reviews

  • Finish the match and leave the post-game screen.
  • Open Reviews. Your match appears as soon as deadlock-api has it, usually within a few minutes and at most about 40.
  • If it says Pending, press Try again later.
You should see
A Win or Loss stamp, how far ahead or behind in lane souls you were at 9:00, and where your souls came from. Abandoned matches and matches with no result are labelled as such, never as a loss.

Builds

  • Community builds: pick a hero, browse the in-game community builds, import one.
  • Library: see your builds, with each item tile in its category colour and a count per category. Press Make active on one.
  • Build maker: make your own. Name it, add sections, search for items, move them earlier or later.
You should see
Builds that use items removed by a patch are flagged Needs update.

Settings

  • Try every text size from 75% to 200%. Everything should stay readable and reachable.
  • Check your Account ID.
  • Read the Privacy notes.

Tester habits

  • Play normally. Don't change how you play for the app.
  • Try it with the window on a second monitor and behind the game.
  • Quit and reopen it between matches at least once.
  • If anything looks wrong, mark it in the moment, not later.
04

Report a problem

Mark it, then send the file

  1. When something looks wrong, press Mark a problem on Home or Live and type one line about it. This puts a timestamp in the record so the developer can find the moment.
  2. After your session, go to Settings, then Save diagnostics file. You'll see a summary of what's inside. Add a note if you like. Tick Include my Account ID only if you're happy for the developer to look up your matches.
  3. The file stalemate-diagnostics-<date>.zip is saved to your Downloads folder. Send it to whoever invited you, with a sentence about what happened.

Nothing is ever uploaded by the app. You send the file yourself, and everything inside is plain text you can read first. You can turn the recording off in Settings.

What's in the file

  • App version, package type, system and desktop
  • Every setup check and its result
  • For each match: how fast it was detected and connected, the delay, errors, how fast scouting and the review arrived
  • Processor and memory use during matches
  • Counts of which screens and buttons you used
  • Your problem notes, and the app's own log

What's never in it

  • Your API key or any password
  • Other players' names or IDs
  • Chat
  • Match recordings or the game's log file
  • Your own Account ID, unless you tick the box
  • Folder names outside Stalemate's own

A final check refuses to save the file if any of these slips through.

05

Not in this Alpha

  • The in-game overlay. Alpha is the main window only.
  • Live item recommendations (what to buy against this enemy team).
  • The full coach-style review with key moments and the optional AI coach. Alpha reviews are stats only.
  • Ranked-only behaviour, such as the pre-game hero swap phase, hasn't been tested. If you play ranked, tell us how scouting behaves.
  • Final art and icons. Hero and item pictures are downloaded when the app runs, and some screens show placeholders.
06

Windows checklist

For a first Windows run. It takes one match.

  1. Install with the .msi (section 01). Note whether SmartScreen appeared and whether Run anyway worked.
  2. Open Stalemate. Note which setup checks pass. Steam found should pass straight away.
  3. Add -condebug to Deadlock (section 02), start the game, reach the menu, press Check again.
  4. Play one match with Stalemate open. During the match, look at Scouting and Live.
  5. After the match, wait for Reviews to show it.
  6. Save the diagnostics file (section 04) and send it, with a line on anything odd.
  7. Optional: run the portable .zip too and say whether it behaved the same.
